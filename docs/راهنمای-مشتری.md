# راهنمای مشتری — سامانه پرسنل کافه

نسخه: **1.0.1**  
فایل نصب: `CafeManagement_Setup.exe`  
ویندوز: ۱۰ و ۱۱، ۶۴ بیتی

این برنامه برای ثبت ورود و خروج پرسنل کافه است و به اینترنت یا نصب Python نیاز ندارد.

## نصب

1. فایل `CafeManagement_Setup.exe` را اجرا کنید.
2. اگر ویندوز هشدار امنیتی نشان داد، به خاطر نداشتن امضای دیجیتال است. فقط اگر فایل را از خودتان گرفته‌اید ادامه دهید.
3. مسیر نصب را انتخاب کنید. مسیر پیش‌فرض داخل پوشهٔ کاربر است و می‌تواند فاصله داشته باشد.
4. در صورت تمایل میانبر Desktop را فعال کنید. میانبر منوی Start همیشه ساخته می‌شود.
5. پس از نصب، برنامه را از میانبر «سامانه پرسنل کافه» باز کنید.

## اولین ورود مدیر

1. در صفحهٔ اول «پنل مدیر» را بزنید.
2. رمز پیش‌فرض `admin` است.
3. بعد از ورود، دکمهٔ «تغییر رمز» را بزنید و رمز جدید را ذخیره کنید. رمز جدید حداقل ۴ کاراکتر است.

## کار روزانه

- **کیوسک پرسنل:** نام کارمند را انتخاب کنید، سپس «ثبت ورود» یا «ثبت خروج». درخواست مرخصی هم از همین صفحه است.
- **پنل مدیر:** ثبت و ویرایش پرسنل، شیفت (شیفت شب هم مجاز است؛ مثلاً ۲۲:۰۰ تا ۰۶:۰۰)، کارتابل مرخصی، اصلاح تردد ناقص، حقوق و گزارش ماهانه.
- **گزارش ماهانه:** ماه شمسی را انتخاب کنید. ستون‌ها شامل تاریخ، ورود، خروج، کارکرد و وضعیت روز هستند.
- **خروجی اکسل:** در همان صفحه دکمهٔ «دریافت خروجی اکسل» را بزنید و محل ذخیره را انتخاب کنید.
- **پشتیبان:** دکمهٔ «پشتیبان» یک کپی از پایگاه داده می‌سازد. «بازیابی» اطلاعات فعلی را با آن فایل عوض می‌کند.

برای بستن هر پنجره از دکمهٔ X یا دکمهٔ بازگشت/خروج استفاده کنید. با بستن صفحهٔ انتخاب نقش، برنامه بسته می‌شود.

## محل اطلاعات

اطلاعات پرسنل و تردد اینجا می‌ماند و با حذف برنامه پاک نمی‌شود:

`%LOCALAPPDATA%\CafeManagement\cafe.db`

برای پاک کردن خودِ اطلاعات، بعد از حذف برنامه این پوشه را دستی پاک کنید. قبل از به‌روزرسانی یا تعویض رایانه، از داخل برنامه یک پشتیبان بگیرید.

## محدودیت این نسخه

نصب روی یک ویندوز تمیز که Python ندارد، هنوز جداگانه تأیید نشده است. سازگاری با همهٔ رایانه‌ها را فرض نکنید.
